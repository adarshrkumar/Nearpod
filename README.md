# CamApp

A web-based photo capture application using your device's camera.

## Features

- Specify how many photos to capture (1-50)
- Live camera preview
- Photo counter and status display
- Gallery view of captured photos
- Works on desktop and mobile browsers

## How to Use

1. Enter the number of photos you want to take
2. Click "Start Capturing" to initialize the camera
3. Click "Capture Photo" to take each photo
4. Click "Done" when finished
5. View your photos in the gallery

## Browser Support

Requires a browser with WebRTC support (camera access):
- Chrome, Firefox, Safari, Edge (modern versions)
- iOS Safari (with `playsinline` support)

## Tech Stack

- HTML/CSS/JavaScript
- WebRTC (getUserMedia API)
- Canvas API for photo capture
- Hosted via GitHub Pages
